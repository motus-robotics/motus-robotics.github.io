How to Read the Catalog

Embodiments, Capability Labels and Evidence

WuJi-1, WuJi-2 and Sharpa are the embodiment labels used by the project for these clips. Capability labels mirror the original Motus2 interface: Dexterous denotes fine manipulation, Tactile marks contact-sensitive demonstrations, Memory covers long-context tasks, Generalize denotes object-variation evaluations, and Normal groups everyday manipulation rollouts.

The catalog describes what is visibly recorded and does not infer unreported success rates, latency, or benchmark statistics. For the method, training setup and aggregate experimental results, use the official Motus2 project page and arXiv:2608.30237. The project page also explains the model's working memory, tactile expert and closed-loop self-evolution.
